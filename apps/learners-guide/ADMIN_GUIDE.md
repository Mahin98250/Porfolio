# Admin Guide - Learner's Guide Platform

## Overview
The Admin Portal provides management control over the complete learning platform.

## Main Responsibilities

### Student Management
- Create and manage student records.
- View student information.
- Manage student portal access.

### Teacher Management
- Manage teacher accounts.
- Assign teachers to required classes/batches.

### Attendance Management
- Monitor attendance records.
- Review attendance data across students.

### Leave Management
- View student leave requests.
- Approve or reject leave requests.
- Track leave history.

### Fees Management
- Manage fee information.
- Review pending and completed payments.

### Results Management
- Manage marks and test results.
- Review student performance information.

## Security
- Admin access should only be provided to authorized users.
- Do not share admin credentials.

## Deployment Notes
- Ensure Supabase environment variables are configured.
- Verify role permissions before production release.
