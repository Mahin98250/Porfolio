# User Guide - Learner's Guide Platform

## Overview
Learner's Guide provides separate portals for students, parents, teachers, and administrators.

## Student Portal
Students can:
- View their profile.
- Check attendance.
- View marks and results.
- Access study materials.
- Submit leave requests.

## Parent Portal
Parents can:
- View linked student information.
- Monitor attendance.
- Check fees information.
- View results and academic progress.
- Submit and track leave requests.

## Teacher Portal
Teachers can:
- Manage assigned classes.
- Record attendance where permitted.
- Access assigned student information.

## Installation
The platform can be installed as a Progressive Web App (PWA) on supported devices.

## Account Safety
- Keep login credentials private.
- Log out from shared devices.
- Report access issues to the administrator.
