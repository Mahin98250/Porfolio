# Futuristic 3D Developer Portfolio

An ultra-modern cinematic portfolio website for Mahin Patel built with React, Vite, Tailwind CSS, Three.js, React Three Fiber, Framer Motion, GSAP, and Lenis.

## Features

- 3D Hero Section
- Cyberpunk UI
- Glassmorphism Design
- Interactive Particles
- AI Assistant Widget
- GitHub API Integration
- Animated Skill Orbit
- Cinematic Project Showcase
- Matrix Rain Toggle
- Command Palette
- Interactive Terminal
- Custom Cursor
- EmailJS Contact Form
- Dark / Light Mode
- Mobile Optimized
- SEO Optimized

## Tech Stack

- React + Vite
- Tailwind CSS
- Three.js
- React Three Fiber
- Framer Motion
- GSAP
- Lenis
- React Icons
- EmailJS
